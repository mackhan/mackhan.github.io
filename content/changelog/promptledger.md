## v0.6.16 · 2026-10-23

### 新功能
- **桌宠（气泡）默认开了**，不用再去设置里翻——它是「现在谁在干活」最直观的出口，默认关着等于没人看得见。开机自启也在第一次启动时替你登记上（之后你自己改过就不再动它）。
- **CodeBuddy 开着的项目认得出来了**（比如 KVMini）。根因：Windows 装的 CodeBuddy CN **不留会话正文**（正文在云端，本地是空目录），日志里也没有工作区路径，所以以前只看到 WorkBuddy、CodeBuddy 像没开一样。现在改读 VS Code 系通用的「最近打开的工作区」（Windows / Mac 同一个文件），并且只在应用确实在运行时才认，状态按「待命」显示。

### 改进
- **托盘图标重画**：琥珀色气泡 + 三根递增的柱子。以前 Windows 上用的是 App 图标缩一版，缩到 16 像素就是一团糊；现在按小尺寸重新画了几何（对齐到 2 像素网格），深色 / 浅色任务栏上都看得清，Mac 的单色模板同步更新。

### 修复
- **采集钩子默认自己接上**：每次启动看一眼有没有漏的，有就补装。Windows 上客户端正占着它的配置文件时这次装不上（这是 Windows 的限制，不是出错），下次启动会再试——哪次开机那个 Agent 没开，就自动接好了。这三件事都还能在设置里关掉。

## v0.6.14 · 2026-10-23

### 改进
- 额度来源的开关**只管 Cursor / Claude Code / Codex / Copilot / Gemini 这几家**，管不到腾讯额度那条（那条读的是公司额度面板自己的登录态，本来就是本工具的主额度）。设置页的措辞一直是「其它来源的额度」，注释现在也写明了这个范围。

## v0.6.13 · 2026-10-23

### 新功能
- 设置 → 采集里可以关掉（「手册交给对话里的 AI 自己维护」），关掉就退回纯只读参考。

### 改进
- **三份手册交给对话里的你维护。** 新会话带上项目手册时，会顺带要求你「有阶段性进展、或这次对话结束前，把这次定下来的事、新加的、还没做完的写进手册」。以前是靠定时任务另开一个会话去写，一天才一次（不及时），而且要额外花一份模型额度——手册该由正在干活的那个会话顺手写掉。
- 写法也一起带上：「是什么」以代码为准，「为什么」和「还没做完什么」以这次对话为准，没依据的不写；缺哪份建哪份，只改相关条目，不必重写全文。项目自己有文档规则的（AGENTS.md、memory-bank 之类）仍交给它自己的规则，不重复要求。

## v0.6.12 · 2026-10-23

### 新功能
- 为什么统一：以前两端各签各的，而「最新版本号」在两端是共用的（清单里只有一个版本号），所以每一版都得两边都打包、都签名，任何一端漏发，那一端就悄悄停在旧版本。统一成一把钥匙之后，Windows 的安装包可以在 Mac 上签名（包只是个文件，签名并不需要 Windows），那一端只剩下「把包构建出来」这一步。

### 改进
- **Windows 这一版请手动装一次。** 自动更新的签名钥匙两个平台统一成一把了。之前装在 Windows 上的那份认的是旧钥匙，之后所有的更新包它都验不过——表现是「点更新一直装不上」。手动装完这一版，自动更新就恢复正常，以后不用再管。

## v0.6.11 · 2026-10-23

### 新功能
- **额度来源可以关了。** 读 Cursor / Claude Code / Codex / Copilot / Gemini 的额度，要带着本机的登录凭据去请求它们（Cursor 的会话 Cookie、Claude / Codex 的 OAuth token、GitHub 的 PAT），而且每两分钟就来一次——以前装了就没地方关。现在设置 → 额度里有总开关和逐家开关：关掉就一家都不读，连凭据文件都不碰。

### 修复
- 顺带修掉一处：关掉再打开时，上一次攒下的失败不再拖着——重新打开等于立刻重试。

## v0.6.9 · 2026-10-23

### 改进
- **额度不再只有一条**：以前面板上只有一个「本月额度」，那是公司内部的额度池。Cursor、Claude Code、Codex、Copilot、Gemini 各有各的额度，量纲还不一样——有的是金额，有的是请求数，有的是「5 小时 / 7 天」这样的时间窗口百分比。现在一家一张卡分开列，各按各的画法：金额画「¥已用 / ¥总额」，次数画「150 / 500 次」，时间窗口每个窗口一条进度条带自己的重置时间。
- **菜单栏那条还是一条**，按「金额优先、取不到才退化」挑：有额度池就显示它，没有才退化到别家，并说清是谁的额度（比如「Claude Code 已用 61%」）。
- **Copilot 要填一次 PAT**：它自己的 OAuth token 查不了计费接口，要一个带 Plan 读权限的 fine-grained PAT。设置 → 额度里填一次；留空就不显示它那张卡。
- **Gemini 是估算**：Google 没有公开的额度接口，只能数今天的本地会话数和 Token。卡上标了「估算」，也不编一个分母出来——不知道账号是哪一档，写 1000/天就是编的。

### 修复
- **只列真正取得到的**：装了并登录过的才出现，取不到就整条不显示（不弹一张取不到数的卡占地方）。这几个接口都是各家自己的内部接口、没写进文档，随时可能变，所以它们取不到时绝不能影响整个面板。

## v0.6.8 · 2026-10-23

### 新功能
- **项目名的取法又过了一遍**：一个项目真的可以叫 `a`，但单字母的目录名原先会被当成盘符扔掉；反过来，uuid 形状的目录名（Cursor 建的那种工作区目录）原先反倒会被当成项目名显示出来。两处都改过来了。

### 改进
- **采集侧补了测试**：项目名怎么取、mac 和 Windows 两种日志格式怎么认、换窗口之后用量归不归到新项目、重复行去不去重——这些原来一条测试都没有，而这次 review 里挖出来的问题全在这块。

### 修复
- **CodeBuddy 的会话现在有标识了**：Windows 上这一列一直是空的，看着只是少一列，实际是「指派项目 / 隐藏会话」对 CodeBuddy 整条都点不动——程序会拒绝空标识，点了只会弹「会话标识格式不对」。现在标识从日志里的请求 id 取（一次提问一个，同一提问的多个步骤共用）。

## v0.6.7 · 2026-10-22

### 新功能
- **Windows 上终于有数据了**：采集脚本一直在 macOS 的目录里找 CodeBuddy 的用量日志（`CodeBuddyExtension/Logs/...`），Windows 上根本没这个目录，所以 CodeBuddy 那一栏永远是空的，面板看着像坏了。现在按 Windows 的真实位置找（CodeBuddy CN 的 `logs/<启动时间>/window1/exthost/腾讯云代码助手*.log`），项目也认得出来了——KVMini 这类项目第一次出现在面板里。

### 改进
- **活跃会话也先记下来**：以前一个会话文件要「30 分钟没人动」才解析，于是你正在用的那个会话在今天这一栏里永远是 0，越用越觉得没数据。现在照样解析已经写完的部分，最多 60 秒重读一次，今天的数据是实时的。
- **项目名不再是一长串路径**：工作区目录名 `c-Users-nierhan-WorkBuddy-<项目>` 现在只取末尾有意义的一段（路径里的时间戳、会话 id 会跳过）；实在取不出来就归到 WorkBuddy，不再把整条路径当项目名显示在项目列表里。
- **CodeBuddy 的工作区会跟随**：日志里换了窗口、换了项目，之后的用量就归到新项目；以前整份日志都算在第一个工作区头上。

## v0.6.6 · 2026-10-22

### 改进
- 每个 Agent 一种读法：WorkBuddy 读会话记录尾部，CodeBuddy 读它自己的 index.json （这一轮是 running 还是 complete）。以前只认一种格式，CodeBuddy 一律「认不出」， 退回按文件时间估——子代理还在跑的时候会被判成「说完了」。
- 「等你决策」不再显示成灰色：这一轮没跑完就一直算生成中。记录说在跑、但两分钟 没写文件时显示「生成中 · 没动静」（可能在等你点确认，也可能在跑长命令）。
- 桌宠悬停标签改成多行：项目名最多两行，状态和 Agent 一行。以前一行不换行加省略号， 项目名一长整块只剩「…」。
- 三个窗口的状态文案和排序统一到一张表（以前桌宠叫「等你回复」、刘海叫「等响应」、 主面板没有字，排序也不一样）。

### 修复
- 完成提醒更严：只有「生成中 → 等你回复」才响。没动静 / 卡住 / 应用退出不响。

## v0.6.5 · 2026-10-22

### 改进
- 修一个一直没人发现的语言 bug：SDK 初始化时不会去问系统语言（它的默认值就是英文），所以哪怕你的系统是中文，「更新日志」「推荐文案」「反馈邮件模板」也全是英文。现在按系统语言走，设置 → 通用 → 语言里也能手动切（跟随系统 / 中文 / English）。
- 主题：浅色 / 深色 / 跟随系统，设置 → 外观里三选，选了立刻生效；选「跟随系统」时系统切深浅会实时跟着变。
- 反馈改成先在应用里写：写完点「发出去」，邮件客户端里正文已经写好了。以前点一下会弹一个只有占位符的空白邮件窗口，看着像测试邮件。
- 「隐私政策」现在指向真正的隐私政策页；「数据边界」（哪些数据会离开这台机器）仍然在手机分组里，两者不是一回事。
- **Windows 版首发**：托盘常驻，鼠标移上去看今日轮次与 Token，点一下打开面板（今日 / 本周 / 项目 / 设置），右键是立即刷新、打开周报目录、版本号、退出。安装包不用管理员，桌面和开始菜单都有快捷方式。
- 关于更新签名密钥：换了一把新的（旧的那把不在这台 Windows 上，新公钥已经写进程序）。这一版的 Mac 包是换钥之前签的，所以你现在的 Mac 客户端照样能自动更新上来，不用手动装；影响是从下一个用新公钥构建的版本开始——那一次换钥之前装的客户端需要手动装一次。Windows 是新装，不受影响。

### 修复
- 设置页排版修了一遍：返回按钮和分组标题原来挤在一起。分段控件、按钮、输入框的手感统一了：按下微缩、统一焦点环、深色下选中项不再糊成一片。
- 跳转逻辑抽成一个模块：桌宠气泡、刘海面板的行、主面板项目卡现在共用同一份（连点只算一次，失败会说一句人话）。

## v0.6.4 · 2026-10-22

### 新功能
- 手机端：今日 / 本周 / 本月 / 本年四档，多台电脑做一个项目时，项目卡点开能看每台机器各自的数据。

### 改进
- 「已完成」现在是真的完成：以前 WorkBuddy 在干活期间也会发通知，被当成「AI 停下了」，于是显示完成时其实还在调工具。现在改成直接看会话记录的最后一条——还在想 / 还在调工具就是「生成中」，AI 真回了话才算「等响应」。顺带一个大好处：跑一个三分钟的命令时，也不会中途掉出「生成中」。
- 点桌宠或刘海里的项目，会直接切到 WorkBuddy 里对应的那个对话（它把多个任务放在同一个窗口的不同空间里，以前只把应用切到前面，等于没切）。
- 修一个真会坑人的 bug：装好以后再跑一次 `pl install`，pl 会把自己覆盖成空文件（读和写是同一个文件，先被截断），之后所有命令静默退出。现在会认出「我就是装好的那一份」，不再自我覆盖。

### 修复
- 「立即同步」现在给明确结论：成功说清推到哪个仓库哪个分支、手机怎么验；失败说清下一步怎么办。
