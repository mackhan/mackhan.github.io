## v0.4.17 · 2026-10-30

### 新功能

- 新增**锁在本机**：按一下就把光标锁在当前这台，鼠标撞到屏幕边缘也跨不过去，但连接、剪贴板、文件传输照常 —— 跟「断开」不是一回事。默认**不绑任何快捷键**（锁住之后鼠标过不去，只有你自己录过键才知道有这个功能）；锁住时气泡、托盘图标和设置页都会显示，鼠标顶到边缘还会给一次提示
- 新增**对端动作**：你正在控制对端时，可以一键让它锁屏或静音。这跟「按键盘」不一样 —— 是对端在自己本机上执行，不需要你按出 Win+L 这种 Mac 键盘上根本不存在的键。同样默认不绑快捷键
- 新增**组合键替换**：默认一条规则都没有。加一条（比如「⌘L → Win+L」）之后，这个组合就不再走全局的键位映射，直接按你指定的发 —— 于是 ⌘C 照旧复制，⌘L 变成锁屏

### 改进

- 修饰键映射新增一档**「Mac 的 Control 当 Windows 的 Win 键」**：默认档下跨到 Windows 后没有任何键能当 Win 键用，选这一档后 ⌃L = Win+L 锁屏、⌃E = 资源管理器，而 ⌘ 仍然当 Ctrl

### 修复

- 修好**「全屏时自动不跨屏」**（默认关）：以前开了这个开关，鼠标还是能跨过去，只是跨过去之后键鼠发不出去 —— 等于切过去了但没反应。现在直接不跨。只挡「出去」不挡「进来」：对端仍然可以来控制你

## v0.4.16 · 2026-10-29

### 新功能

- 新增**按应用规则**：前台是虚拟机（Parallels / VMware / VirtualBox / UTM）、远程桌面（RDP / ToDesk / 向日葵 / TeamViewer / AnyDesk）或 Steam 时，按规则决定这次输入还跨不跨屏。内置 20 条推荐规则，也可以在设置里加自己的
- 新增「全屏时自动不跨屏」开关（默认关）：打开后只要前台窗口铺满整块显示器，鼠标键盘就都不跨屏
- 新增**剪贴板历史**：记住最近复制的 10 条，点「复制」写回剪贴板后自己按 Cmd / Ctrl + V。只存内存、退出即清；密码、银行卡号、私钥这类内容不会记录，也可以一键暂停记录

### 改进

- **同平台不再绕一道翻译**：Mac 连 Mac、Windows 连 Windows 时键盘直接发原生键码，以前要先转成 X11 键码再转回来，F13~F20、PrintScreen 这些键会在这一来一回里丢掉
- 显示器布局预览改成按**真实分辨率比例**渲染（以前小屏会被拉到和 4K 屏一样大），并加了「测试」按钮：在预览里沿当前方向走一遍，看清光标从本机哪条边出去、落在对端哪块屏
- 传文件时**鼠标更跟手**：分片从 48KB 降到 16KB（与 TLS 单条记录对齐），延迟采样从 3 秒一次提到 1 秒一次 —— 以前网络已经堵了 3 秒才被感知，期间让位机制基本是失聪的

## v0.4.15 · 2026-10-28

### 改进

- 跨屏复制文件现在真的是「复制 → 粘贴」了：对端收到文件后会把它们放进**自己的剪贴板**，你直接按 Ctrl+V / Cmd+V 就能粘到想去的位置，不用再去接收目录里找。文件照旧也保存一份在接收目录
- 可以直接把文件拖到桌面气泡上发给对端了 —— 以前只有主窗口能接收拖放，主窗口收起来时想传文件得先把它打开。拖上去气泡会显示发送进度和结果
- 传文件时会显示**速度和剩余时间**了（不只是百分比），大文件传多久心里有数，体感接近在本机拖动一个文件。气泡上同样看得到进度
- 对端发来的文件收齐后，气泡也会提示「收到文件，可直接粘贴」，不用开着主窗口等
- 设置里的「文件接收目录」留空时，会直接把实际生效的目录（系统「下载」）显示在输入框里，不用再猜文件会落到哪

## v0.4.14 · 2026-10-28

### 新功能

- 新增「共享时阻止自动锁屏」（默认开启）：连接期间拦住空闲自动触发的锁屏、屏保和显示器休眠，避免共享到一半被锁掉。只拦自动的，你手动按 Win+L / Ctrl+Cmd+Q 照样能锁；断开连接立刻恢复系统原本的节能设置。不想要可以在设置里关掉

### 改进

- 扫描终于真的能扫到设备了：局域网广播发现的「应答端」以前写好了却从来没启动过，所以每次扫描都悄悄退化成把整个网段挨个试一遍（慢、还经常漏）。现在应答端接上了，同一个网段里的设备一般是秒出
- 扫描结果里点「连接」不再报「缺少 IP」：列表项以前没有 ID，点连接必然失败
- 信任过的设备列表里加了「连接」按钮：直接用上次连过的地址发起连接，不用每次开 App 都重新扫一遍局域网；不想要了还是可以「取消信任」
- 首次配对改成 4 位配对码：两台电脑上各显示同一个 4 位数字，比对一致就可以信任，不用再逐位核对那一长串证书指纹。设置里可以关掉，关掉就退回只显示完整指纹
- 锁屏不再是「假装还连着」：Windows 和 Mac 现在都能知道自己被锁住了 —— 锁屏后明确暂停跨屏控制并告诉你原因（锁屏状态下系统不允许收发键鼠），解锁后自动恢复。以前 Windows 会在锁屏期间每 5 秒反复重装钩子，日志刷屏还可能打断输入
- 锁屏期间对端送来的键鼠不再堆积：解锁那一刻不会再突然「补放」一串点击和输入

## v0.4.13 · 2026-10-27

### 改进

- 桌面气泡拖动时不再带着展开的详情卡一起跑 —— 拖动前会先把卡片和菜单收掉，收起真正落地后才交给系统拖动
- 气泡能贴住屏幕边缘了：之前贴到边上偶尔会被挤回中间一点，因为展开时的窗口让位被当成了气泡位置
- 打开主窗口后桌面不再残留半截气泡卡片：隐藏前会先把窗口收回小球并同步界面状态
- 气泡拆成两层：通用的桌面悬浮球框架（拖动、贴边、展开收起、右键菜单）与 KVMini 自己的内容，以后做别的悬浮球可以直接复用
- 双机键盘控制抽成独立模块，键盘去向只有一份规则：光标在哪台机器，两台机器的键盘都输入到那台；被控端打字不再被后台的钩子重装打断
- 改了显示器布局或换了对端分辨率后，边缘检测立刻按新的屏幕尺寸重建，不用等重新连接才对上
- 跨屏拖拽的两端共用同一份状态机，不再各写一份（之前改一处漏一处，拖拽反复出问题就是这么来的）
- 跨屏拖拽失败不再「静默」：收不齐、提前松手、会话被取消或卡死、拖拽捕获没起来、文件没发出去 —— 每一种都会明确告诉你发生了什么、文件在哪、还能怎么传。以前这些只写进日志，你看到的就是「拖过去了什么都没发生」
- 拖拽没读到文件而改用剪贴板时，会明确说明「发的是剪贴板里的文件，不是你拖的那个」；剪贴板内容与上次相同时也会说明为什么什么都没发生
- 把文件拖到屏幕边缘又拖回来，不会再在接下来几秒内把**上一次**拖的文件误发给对端（Windows 端）
- Mac 上拖文件跨屏更稳：拖拽剪贴板里残留的旧内容不会被当成这次拖的；在屏幕边缘来回蹭也不会把同一批文件重复发过去
- 拖拽中途断开或取消时，本机不会再一直「按着左键」：卡住的会话会自动收回代按的按下，Windows 端取消后最多 1 秒必定生效
- 用鼠标右键拖文件跨屏时会明确提示「只支持按住左键拖」，不再给一条无关的「先复制文件」提示
- 拖拽捕获线程没起来或中途退出时会立刻提示，并允许下一次开启共享时重新拉起，不再静默失效到重启 App
- Mac 上不会再发出**上一次**拖的文件：拖拽剪贴板拖完不清空，只有「这次按下之后真的变过」才认，之前按下瞬间就会把里面的旧内容读回来
- 拖拽中途断开或取消后，本机不会再一直「按着左键」，也不会在之后的几十秒里悄悄拒绝新的拖拽

## v0.4.9 · 2026-10-23

### 新功能

- 新增「Ctrl+空格 切输入法」开关（默认开）：用 Windows 键盘按 Ctrl+空格，Mac 收到的是 Control+空格（切换输入法），不再被统一键位映射转成 Cmd+空格（Spotlight）；Ctrl+C 等其它组合照旧

### 修复

- 修复「双机键盘控制」下被控端（Windows）键盘完全失灵：以前被控端把本机键盘转发给对端并在本机吞掉，但被控端根本不发帧、主控端收到也不注入，结果两台都收不到。现在键盘真正跟随光标 —— 光标在哪台电脑，两台的键盘都输入到那台
- 修复改了显示器布局（左右/上下）后本机仍按旧方向跨屏：保存布局后立刻重建边缘检测；对端同步过来的布局也会先镜像再落盘
- 修复布局预览里看不到对端的显示器：显示器清单现在随连接同步，插拔显示器也会告诉对端
- 修复单击桌面气泡打不开主窗口：macOS 的系统拖动是模态的，会把 mouseup 一起吞掉，现在要真的移动超过一小段距离才交给系统拖
- 修复拖动气泡时状态提示乱闪：拖动期间不再展开/收起详情卡
- 修复 Mac 上最小化后不显示桌面气泡、点 Dock 图标也叫不回主窗口：最小化不再依赖窗口尺寸变化事件，Dock 点击单独处理
- 修复偶发的巨大延迟和「卡一下然后重连」：Ping / Pong / 心跳不再和键鼠挤在同一条发送队列里排队，延迟数字不再被排队时间污染
- 修复设置页改完「修饰键映射」要重启 App 才生效
- 修复用 Mac 键盘在 Windows 上按 Caps Lock 后输入全是大写、再按也关不掉：Mac 把 Caps Lock 当长按键（只发按下、下次才发释放），Windows 却是切换键（要完整的按下+释放才切换）。现在 Windows 端把每次状态变化转成一次完整的按下+释放
