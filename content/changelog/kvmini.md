## v0.3.4 · 2026-10-14
### 新功能
- **跨屏拖拽文件（Windows 端）**：从资源管理器拖着文件越过屏幕边缘，文件会传到另一台电脑并在松手处放下，不用先复制再粘贴
### 修复
- Windows 上更新后，另一台电脑可能卡在被控制的状态（更新安装前没有先归还控制权）

## v0.3.3 · 2026-10-11
### 改进
- Mac 安装包经过苹果公证，从网页下载后可以直接打开
- 更新弹窗排版修正：按钮固定在底部，说明较长时只滚动说明
### 修复
- 在设置页点“检查更新”，已是最新或检查失败时没有任何提示

## v0.3.2 · 2026-10-10
### 新功能
- **自动更新**：发现新版本时弹窗显示更新说明和下载进度，下载后校验签名再安装；可以“跳过此版本”或“明天提醒我”
- 新增 Intel 芯片 Mac 的安装包
### 改进
- 重启完成更新前，会先归还控制权并恢复本机键鼠，不会让另一台电脑卡住
### 修复
- 版本号比较错误：0.3.10 会被当成比 0.3.9 旧，永远检测不到更新

## v0.3.1 · 2026-10-10
### 新功能
- **传输加密**：键鼠、剪贴板、文件全部经 TLS 1.2 / 1.3 加密，无法关闭
- **首次连接核对指纹**：连接新设备时两端都显示对方的证书指纹，核对一致后点“信任并连接”，之后自动信任
### 改进
- 复制多个文件后，跨屏或复制即传会把全部文件一起发过去（此前只发第一个）
- 传文件夹或多个文件时，“取消”会取消整批剩余文件
- 文件接收目录可以用系统文件夹选择框挑选，并检查目录可写
### 修复
- 修复加密后可能出现的“粘键”
> 注：0.3.1 起只能与同为 0.3.1 或更新的版本互连（旧版本不加密）。两台电脑请同时升级。

## v0.3.0 · 2026-10-09
### 新功能
- **文件夹与多文件传输**：把整个文件夹或多选的文件拖进窗口，自动排队依次发送，进度显示「第几个 / 共几个」
- **断点续传**：断网、取消或对方重启后，再发同一个文件会从中断处继续，不用从头传
- **自定义接收目录**：设置 → 通用 → 文件接收目录（留空则存到系统「下载」）
- **断线自动重连**：按 1、2、4 秒……（最长 30 秒）的间隔自动重试，界面显示重试次数；手动断开后不会自动重连
### 改进
- Windows 上用画图、Office 等老应用也能直接粘贴从 Mac 传来的图片
- 网页内容粘贴到终端这类只收纯文本的地方，会自动转成纯文本，不再粘出空白；备忘录、写字板、Word 之间互相粘贴时保留格式
- 插拔显示器、合盖唤醒后，屏幕布局自动刷新，不用手动刷新或重连
- 托盘菜单支持中英文切换
- 修改监听端口失败时给出准确提示，不会再误报「已恢复」
- 版本过旧的设备不再允许连接，避免出现难以排查的随机断连
### 修复
- 菜单栏出现两个 KVMini 图标、图标显示成白色方块
> 注：本版本的传输尚未加密，0.3.1 起已全部加密。

## v0.2.7 · 2026-09-30
### 新功能
- **鼠标侧键设置**：默认原样传递第 4、5 键，Logitech Options、BetterTouchTool 等工具里的自定义映射继续有效；也可以改成「前进 / 后退」
- **剪贴板支持图片**：截图后可以直接在另一台电脑粘贴（上限 8MB）
- **剪贴板支持富文本**：网页、文档里复制的内容粘贴后保留格式
- **复制即传文件**：在一台电脑上复制文件，会自动传到另一台的下载目录；先复制文件再把鼠标移过去，文件也会跟着过去。可在「设置 → 通用」关闭
- 连接历史可以逐条删除
### 改进
- 文本同步上限可以在「设置 → 通用」里调整（默认 10MB），超出上限的内容整条不同步，不会被截断
- 设置里选择的监听网卡现在真正生效（以前选了也会监听所有网卡）
- 修改监听端口后立即生效，不用重启；失败会自动恢复原设置并提示原因
- 连接状态以真实的握手结果为准，不会先显示已连接、再变成失败
- 连接超时时提示可能是对方 IP 变了
- 用 Mac 触控板控制 Windows 时，轻轻滚动也能响应
### 修复
- 用 Windows 控制 Mac 时鼠标滚轮没有反应
- 用 Windows 控制 Mac 时，键盘上的浏览器前进 / 后退键没有反应（现在会转换成 ⌘[ / ⌘]）
- 跨设备输入时方括号键 [ 和 ] 互换了
