PromptLedger 隐私政策

最后更新：2026 年 10 月 22 日 · 适用于 PromptLedger 0.6.x（macOS）

PromptLedger 是一个本地优先的提示词账本：它统计你每天对 AI 说了多少、花了多少 Token，并把提示词存成可搜索的档案。它没有账号，没有服务器，不要求你登录任何东西。

一、PromptLedger 读取什么

这些数据本来就已经在你自己的电脑上（是各个 AI 工具自己写的记录），PromptLedger 只是把它们读出来、算成统计：

  • 各个 AI 客户端（WorkBuddy、CodeBuddy、Cursor 等）写在用户目录下的会话记录、提示词日志；
  • 你本机 git 仓库的提交记录（用来算「代码行数」和「本周新增」）；
  • 本机的进程列表（用来判断某个 AI 应用是不是开着）。

这些内容一律留在本机，写在 ~/.prompt-archive/ 里，不上传到任何服务器。

二、会离开这台机器的数据

只有两项，而且都可以在设置里关掉：

数据去哪儿内容怎么关
匿名使用统计 统计服务（腾讯云） 只记版本号、功能名（如「搜索」「导出」）、次数、匿名安装 ID。不含提示词、项目名、文件路径、文件内容 设置 → 通用 → 发送匿名使用统计（默认开）
手机同步数据包 你自己指定的 GitHub 仓库 用于在手机上看统计的加密数据包（AES-256-GCM）。仓库里只有密文，解密密钥只在你手机扫的二维码里 设置 → 手机 → 开启手机同步（默认关）

另外，额度数字来自公司内部的额度接口（只读、带访问令牌），只带令牌，不带任何提示词内容。

三、不会做的事

  • 不收集提示词正文、AI 回复正文、项目名、文件路径、代码内容；
  • 不注册账号、不读取通讯录 / 相册 / 定位 / 麦克风 / 摄像头；
  • 不把你的数据卖给、分享给任何第三方；
  • 不在后台偷偷联网（设置页的「断网自检」会跑一遍纯本地查询，证明这一遍没有发出任何网络请求）。

四、数据保留与删除

  • 所有数据都在你的磁盘上，你随时可以删：设置 → 数据 → 存储空间（按时间 / 按 Agent 清理原始存档）；
  • 删掉的会话先进入「最近删除」，30 天内可以恢复，过期后彻底删除；
  • 卸载 App 不会自动删数据（方便你重装后接上），需要时手动删 ~/.prompt-archive/ 即可；
  • 已经上传的加密包：到那个 GitHub 仓库里删掉对应分支即可，你完全控制它。

五、权限与系统能力

  • 通知：仅用于「AI 生成完成」这类提醒，可在系统设置里关闭；
  • 开机启动：可选，默认关，设置页随时可关；
  • 不需要辅助功能、屏幕录制、完全磁盘访问等敏感权限。

六、儿童

PromptLedger 不是面向儿童的产品，也不会有意收集儿童信息。

七、政策变更

隐私政策有实质变化时，会在 App 的更新日志里说明，并更新本页顶部的日期。

PromptLedger Privacy Policy

Last updated: October 22, 2026 · applies to PromptLedger 0.6.x (macOS)

PromptLedger is a local-first ledger for your AI prompts: it counts how much you ask and how many tokens you spend, and keeps your prompts searchable. There is no account, no server, and nothing to sign in to.

1. What PromptLedger reads

All of it is already on your own machine — written by the AI tools you use. PromptLedger only reads and summarises:

  • session transcripts and prompt logs that AI clients (WorkBuddy, CodeBuddy, Cursor, …) write into your home directory;
  • commit history of your local git repositories (for the lines-of-code numbers);
  • the local process list (to tell whether an AI app is running).

None of this leaves your machine. It lives in ~/.prompt-archive/.

2. What does leave the machine

Exactly two things, both switchable in Settings:

DataDestinationContentsHow to turn off
Anonymous usage stats Analytics service (Tencent Cloud) Version, feature names (e.g. "search", "export"), counts, a random install ID. Never prompts, project names, paths or file contents Settings → General → Send anonymous usage stats (on by default)
Phone sync bundle A GitHub repository you choose An encrypted bundle (AES-256-GCM) used to show stats on your phone. The repo only holds ciphertext; the key lives in the QR code you scan Settings → Phone → Enable phone sync (off by default)

Quota figures come from an internal, read-only quota endpoint (access token only — no prompt content).

3. What PromptLedger never does

  • No collection of prompt text, AI replies, project names, file paths or code;
  • No accounts, no access to contacts, photos, location, microphone or camera;
  • No selling or sharing your data with third parties;
  • No hidden network calls — the "offline self-check" in Settings runs a local-only query to prove it.

4. Retention and deletion

  • All data is on your disk: Settings → Data → Storage to purge raw archives by age or by agent;
  • Deleted conversations go to "Recently deleted" for 30 days, then disappear;
  • Uninstalling does not wipe data (so a reinstall can pick up where you left off); delete ~/.prompt-archive/ when you want it gone;
  • To remove uploaded bundles, delete the branch in your GitHub repository — you own it.

5. Permissions

  • Notifications: only for "the AI finished" style reminders; can be turned off in System Settings;
  • Launch at login: optional and off by default;
  • No accessibility, screen recording or full disk access is required.

6. Children

PromptLedger is not directed at children and does not knowingly collect their data.

7. Changes

Material changes are noted in the app's changelog, and the date at the top of this page is updated.
