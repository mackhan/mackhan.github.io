数据边界

PromptLedger 会读你所有的提示词，所以它必须把「什么留在本机、什么会出去」讲清楚。

一句话：提示词、对话、手册、统计全部只写在本机 ~/.prompt-archive/；只有两样东西会离开这台电脑——你主动开启的加密数据包，以及一次额度查询。

逐项说明

数据存在哪会不会离开本机
你写的提示词本机 SQLite（archive.db）不会
AI 回复、工具调用、截图（原始存档）本机 gzip 文件不会
Token 用量本机 SQLite不会
项目手册 / 周报你的仓库 + 本机不会
手机端数据包你的 GitHub 仓库（密文）会（默认关闭）
本月额度公司额度接口会（只发访问令牌）
匿名使用统计一个私有仓库会（可在设置里关）

手机同步：GitHub 上只有密文

开启手机同步后，电脑会先把数据包用 AES-256-GCM 加密，再推到你的 GitHub 仓库。 密钥是 32 字节随机数，只存在于二维码和你的手机里，不上传、不写进仓库、不经过任何服务器。

  • 仓库里拿到密文的人，没有密钥解不开——这是标准 AEAD，没有「弱口令爆破」这条路。
  • 二维码里含密钥，不要截图外传；泄露了就在设置里换一台设备重新配对。
  • 不想留任何痕迹：设置里关掉「开启手机同步」，电脑就再也不上传，仓库里的旧文件自己删掉即可。

额度查询：只发令牌，不发内容

额度来自公司内部的 Tencent Token Dashboard。App 只读它写在本机的登录会话，用同一个接口 GET /v1/me/quota-realtime 取回「已用多少钱 / 总额度」。请求里只有一个访问令牌和设备号， 不包含任何提示词、项目名或路径。这条接口在内网，外部网络下这个功能会直接不显示。

匿名使用统计

默认开启，可以关。只上报：哪台设备、哪个版本、用了哪些功能、用了多久，以及若干数字。 有硬护栏：只允许短字符串（≤64 字）、数字、布尔值，最多 12 个键，数组和嵌套结构一律丢弃—— 就算代码写错，也传不出提示词、路径或项目名。

断网自检

设置里有一个「断网自检」按钮：它跑一遍纯本地的查询，只读本机文件、不发任何网络请求， 然后告诉你读到了多少条记录、用了多少毫秒。这是「本地优先」最直接的证据—— 拔掉网线，今日/本周/项目/文档照常显示。

怎么彻底清空

  • 原始对话存档：设置 → 存储空间 → 选时间范围 → 预览 → 确认删除。
  • 全部数据：删除 ~/.prompt-archive/，重启 App 会重新采集；不想再采集就把各 Agent 的钩子关掉。
  • 手机端：在手机上删除主屏图标 + 清除站点数据；再在 GitHub 上删除同步仓库。

Data boundary (English)

PromptLedger reads all of your prompts, so it has to be explicit about what stays on the machine.

Prompts, conversations, manuals and statistics never leave your Mac — they live in ~/.prompt-archive/. Only two things go out: an encrypted bundle you explicitly enable (AES-256-GCM; the 32-byte key exists only in the pairing QR code and on your phone), and one quota request that carries an access token but no prompt content.

Anonymous usage statistics are opt-out and pass through a strict filter: flat short strings (≤64 chars), numbers and booleans only, at most 12 keys. Arrays and nested objects are dropped, so a coding mistake still cannot leak a prompt, a path or a project name.

The “offline self-check” button in Settings runs a purely local query, makes no network request, and reports how many records it read and how long it took. Unplug the network and the app keeps working — that is the whole point.
